# CCMA Quest

A game-style study quest for the NHA CCMA medical assistant exam, built for people who get bored or distracted studying the usual way.

Play through twelve quests down an ocean map with Otto the sea otter. Right answers damage the enemy, wrong answers cost a heart, and missed questions come back over the following days until they stick.

## What is in it

- 307 original questions across the twelve NHA CCMA test plan areas, with extra coverage of topics from the CMA (AAMA), RMA (AMT) and NCMA (NCCT) outlines
- Battles, bosses, abilities, XP levels and daily quests
- Timed mock exam weighted like the real exam, with a weak-spots report
- Spaced daily review, read-aloud, and an explanation for every wrong option
- Works on phones and computers. Progress is saved in the browser.

## Hosting

The whole app is the single file `index.html`. It has no build step and no server.

To publish with GitHub Pages: open the repository's **Settings**, choose **Pages**, set the source to **Deploy from a branch**, pick the `main` branch and the `/ (root)` folder, and save.
